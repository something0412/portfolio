# Portfolio Website (v2)

This is my personal portfolio website, showcasing my projects, skills, and experience. The site is fully responsive and built using React with a clean, space themed UI. Interactive elements and animations improve user engagement and accessibility.

## Features

- Responsive layout for desktop and mobile
- Animated WebGL galaxy background
- Interactive sections and animations
- Intuitive navigation for an engaging user experience
- Modern, minimalistic UI design

## Tech Stack

**Frontend:** React, JavaScript

**Styling:** Tailwind CSS

**Graphics:** OGL (WebGL)

**Tools:** Vite, EmailJS, React Router

## Deployment

The website is deployed on **Vercel**, providing:

- Secure HTTPS access

- Fast, globally distributed content

- Support for React Router via proper rewrite configuration

Live at: https://www.billle.dev/
